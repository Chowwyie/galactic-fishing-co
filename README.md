# Galactic Fishing Co. — 3D background viewer

Minimal viewer for the procedural 3D slab background (BG3DWorld, V5) in
Godot 4.3 (GL Compatibility, web-export first). Fully procedural — no art assets.

## Run

1. Open `project.godot` in Godot 4.3+ (or run headless: `godot --headless --path .`).
2. Play `scenes/bg_viewer.tscn` (the main scene).
3. Web export: standard Godot web preset; no C# or native plugins.

## Controls

Drag to pan — horizontal moves through the world, vertical changes depth
(the water-column color keys off depth).
