# Galactic Fishing Co.

Top-down 2D space fishing game (Godot 4). Dave the Diver-style diving/harpoon/oxygen
gameplay on a single alien planet — work off your debt to an intergalactic company,
one catch at a time.

Web export first (GL Compatibility renderer), desktop/mobile later.

## Layout

- `scenes/` — Godot scenes
- `scripts/` — GDScript
- `assets/` — pixel art, audio
- `docs/` — design notes

## Status

Scaffold. Prototype next: player movement, harpoon, fish AI, oxygen, one zone, sell screen.
